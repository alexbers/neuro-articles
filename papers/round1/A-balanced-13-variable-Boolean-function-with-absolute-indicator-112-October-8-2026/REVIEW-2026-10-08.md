### 2.2 Леммы и выкладки (проверка построчно)

* Лемма 2.1 (Винер–Хинчин): вывод корректен; второе тождество получается раскрытием квадрата с Σ_a W² = 2^{2n}, r_f(0)=2^n — проверено.
* Лемма 2.2 (r_f(d) ≡ 0 mod 8): инвариантность S∩(S⊕d) относительно x↦x⊕d и отсутствие неподвижных точек при d≠0 — верно; следствие «первое допустимое значение ниже 128 равно 120» — верно.
* Замечание о конкатенации двух бент-функций g_0‖g_1: r(d,1) = 2·Σ_x(−1)^{g_0(x)⊕g_1(x⊕d)} = 2·W_{g̃_0⊕g̃_1}(d) — верно (кросс-корреляция через дуальные), откуда Δ ≥ 2·2^6 = 128 по Парсевалю.
* Орбитные формулы §3 (W_f(u_j) = Σ_i C_{ij}s_i, r_f(u_j) = 2^{−13}Σ_i W_f(u_i)² C_{ij}) и функция стоимости в `acls4.c` (Σ_j sz_j (W_j²−N)²) согласованы с леммой 2.1.
* Утверждение о Lean-технике (14·586 = 8204 ≥ 8192; диапазон 4040 ≤ N_d ≤ 4152 ⇔ |r_f(d)| ≤ 112; фактический диапазон N_d = 4040…4148) — верно.

### 2.5 Новизна и библиография (источники скачаны в `.../paper3/lit/`)

* **[ZZ95]** J.UCS 1(5):320–337, 1995 (PDF с сайта J.UCS, `zz95.pdf`). Conjecture 1 (с. 329) дословно: «Let f be a balanced function on V_n, whose algebraic degree is at least three. Then Δ_f ≥ 2^{½(n+1)}» — **без** знака пола (он появился в более поздней литературе; при нечётном n формы совпадают). Теорема 17: конструкция на V_{2k+1}, сбалансированная, Δ_f ≤ 2^{k+1} (=128 при n=13), «matches the lower bound we conjectured».
* **[TM16]** ePrint 2016/1078 (копия Wayback, `tm16.txt`): Conjecture 1 с полом; «For odd variables n, this conjecture has been disproved for n = 9, 11 in [7], n = 15 in [15] and n = 21 in [14], [10]. Till date, for even n … only for n = 10 [7] and 14 [1]»; те же списки в заключительных открытых вопросах. Журнальная версия: IEEE Trans. IT 64(1):393–402, 2018 (Crossref).
* **[Tang18]** слайды BFA 2018 (`tang18.txt`), слайд 17 «Some counterexamples on Zhang-Zheng Conjecture»: n=15 (Δ=216), n=14 (104/112), n=21 (с поправкой Kavut 2016 DAM), n=9 (24), n=10 (24), n=11 (56). n=13 не упомянуто.
* **[CKW19]** Canteaut–Kölsch–Wiemer, ePrint 2019/848 (Wayback, `ckw19.txt`) и статья arXiv:1908.07445 (`dlct1908.txt`): «disproved first for odd values of n ≥ 9 … namely for n ∈ {9,11} …, for n = 15 …, and for n = 21 …; for even n … n ≡ 2 mod 4 [TM18] … n ≡ 0 mod 4 [KMT19]».
* **[KMY07]** ePrint 2006/181 (Wayback, `kmy07.txt`): введение перечисляет n = 15, 21, 9, 11; 10-переменная функция с Δ=24; ссылка [16] на BFCA 06 (13–15 марта 2006, Руан) — данные [KMY06] подтверждены. Заголовок ePrint отличается от журнального (исправлено в bib). Журнал: IEEE Trans. IT 53(5):1743–1751, 2007 (Crossref).
* **[KY07]** ePrint 2007/321 (Wayback, `ky07.txt`): Приложение B — сбалансированная 13-переменная функция, nl 4036, степень 11, **Δ_f = 536**; [Mai07] ePrint 2007/309 — nl 4034 (страницы ePrint подтверждены).
* **[KY10]** arXiv:0808.0684 / Inf. Comput. 208(4):341–350, 2010 (`ky10.txt`, §3.2): класс 13-переменных DSBF с дополнительной перестановкой π(x_0,…,x_12) = (x_0,x_2,x_4,…) сокращает 2^380 до 2^74 — это в точности класс AGL(1,13) статьи; утверждение статьи о [KY10] верно.
* **[OKK23]** Computers 12(8):159, 2023 (Crossref-аннотация): только чётные n, 12 ≤ n ≤ 26. **[ZPW21]** Information Sciences 575:437–453, 2021, чётные n ≥ 12. **[KMT19]** DCC 87(2–3):261–276, 2019 (Crossref). **[MS02]** IEEE IT 48(1):278–284 ✓. **[GKM06]** Discrete Math. 306(14):1540–1556 ✓. **[BMDC04]** AJC 29 (2004) — страницы **231–247** (PDF журнала), а не 231–248. **[KY03]** INDOCRYPT 2003, с. 121–134 ✓. **[CDJMP22]** arXiv:2202.08743 ✓ (таблица 1: лучшие известные сбалансированные нелинейности 992 при n=11 и 4036 при n=13 — подтверждает замечание 5.1). **[Lean4]** CADE-28, с. 625–635 ✓.
* Поиск новых результатов 2020–2026: WebSearch (несколько формулировок), arXiv API (`abs:"absolute indicator"` — пусто), статья MDPI Cryptography 10(4):43 (2026, аннотация через Crossref: о near-bent функциях, без новых значений Δ), arXiv:2602.00837 (февраль 2026, об идемпотентах; абсолютный индикатор не рассматривается). Ни одного сообщения о сбалансированной 13-переменной функции с Δ_f < 128 не найдено; все найденные источники, перечисляющие контрпримеры, дают для нечётных n список {9, 11, 15, 21}.

**Итог по новизне:** ранее наилучшее известное значение для сбалансированных функций от 13 переменных — 128 (гипотетическая граница, достигаемая конструкцией [ZZ95, Thm 17]); значение 112 ниже и, насколько удалось установить, является первым контрпримером при n=13. Функция принадлежит классу AGL(1,13)-инвариантных (обобщённых диэдрально-симметричных) функций, который использовался в [KY10] для поиска высоконелинейных функций, но ни одна функция из [KY10]/[KY07] не имеет Δ_f < 128 (у них Δ_f = 536 и т.п.); совпадения с известной конструкцией нет.

## 5. Что проверить не удалось / ограничения рецензии

* Мягкие утверждения о поиске, не допускающие конечной проверки: «поиск Δ ≤ 104 в AGL(1,13) не дал ничего лучше 112», «в классах с 380/232/198/140 орбитами не ниже 136», «2^18 шагов в ядре исчерпали 8 ГБ». Воспроизведены только два конкретных запуска (seed 77 и 41).
* Полные тексты [KMT19] и [ZPW21] недоступны (Springer/ScienceDirect закрыты) — проверены только аннотации/Crossref; утверждение «[KMT19, ZPW21, OKK23] treat even n only» подтверждено названиями и аннотациями. Журнальная версия [KMY07] не просмотрена (только ePrint 2006/181, где список нечётных n и ссылка на BFCA 06 присутствуют); значение Δ=56 при n=11 подтверждено слайдами [Tang18] и аннотацией [KMY06] (ResearchGate, через поисковый сниппет).
* ePrint-PDF доступны только через Wayback-копии (2016/1078 — версия от 21.11.2016; 2006/181; 2019/848; 2007/321); DBLP, Semantic Scholar, MDPI и ResearchGate блокировали запросы. Поиск по литературе 2024–2026 ограничен WebSearch/arXiv API; исчерпывающим он быть не может, но никаких следов результата для n=13 не обнаружено.
* Минимум Δ_f среди всех сбалансированных функций от 13 переменных (в т.ч. возможность 120 или 104) по-прежнему неизвестен — статья этого и не утверждает.
