# Рецензия: «New proper circulant weighing matrices from a twin of the Singer construction»

Дата проверки: 8 октября 2026. Проверяющий: Claude (Fable 5.1), отдельная сессия.
Рабочие файлы рецензии: `../.review_scratch/` (скрипты `cw_quick_check.py`, `twin_check.py`, `cw_claims.py`;
оригиналы до правок — в `../.review_scratch/orig2/`).

## Вердикт

- **Главная теорема (шесть явных proper CW) верна.** Все десять сертификатов (6 новых + 4 семейных)
  проверены собственным кодом (CW-условие по определению, properness по всем делителям), списки
  в `lean/Main.lean` побайтно совпадают с `data/certificates.json`.
- **Lean перепроверен независимо:** свежая установка Lean 4.34.1 (core only), `lean Main.lean`:
  exit 0, 4 мин 33 с, 2.0 ГБ; вывод (22 строки `#print axioms`, только `propext`, `Classical.choice`,
  `Quot.sound`; `_proper` — только `propext`) идентичен `lean/lean_output.txt`; `sorry`/`native_decide`
  отсутствуют; sha256 `Main.lean` = e86fc1ee…5186. Определения `IsCW`/`IsProper` соответствуют тексту.
- **Конструкции воспроизведены по формулам статьи, а не по Lean-файлу:**
  - произведение для CW(504,144) из CW(24,9) (на 21ℤ) и CW(63,16) (на 8ℤ): без коллизий, CW, proper,
    **совпадает с сертификатом дословно**; оба сомножителя — именно те, что лежат в репозитории Гордона;
  - структура CW(146,64): B = U+V и B′ = U−V имеют значения в {0,±1,2}, сумму 8, PAF = 64·δ, оба
    инвариантны при x ↦ 2x (сдвиг 0), позиции ±2 образуют планарные (73,9,1)-разностные множества;
    перебор орбитно-постоянных B даёт **32 решения, 112 различных подъёмов, 96 proper** — ровно как в §5;
  - «близнец» W_{1/2} восстановлен над GF(q³) (поле строится как GF(p)[x]/(h), т.е. независимо от
    `twin_singer.py`, который умеет только простые q) для **всех 62 нечётных степеней простых q ≤ 251**
    (авторы проверяли q ≤ 127): всегда W_0 и W_{1/2} — CW(m,q²) с общим носителем, W_{1/2} ≠ ±W_0,
    удвоение A — proper CW(2m,q²). Для q ≤ 19 мои последовательности мультипликатор-эквивалентны
    сертификатам; W_{1/2} никогда не имеет вида ±W_0(tx+s) (проверено для q = 3,5,7,9,11,17,19).
  - Remark 4.7: пункт (2) — для q = 3,5,7 среди Frobenius-инвариантных ±1-узоров на S ровно четыре CW:
    ±W_0, ±W_{1/2} (подтверждено); пункт (3) — среди W_c только c ∈ {0, 1/2} дают CW при q = 5,7,11,13
    (подтверждено); пункт (4) — ровно **186** из 372000 элементов PGL(3,5) дают CW, из них 93 — сдвиги
    ±W_0 и 93 — сдвиги ±W_{1/2} (подтверждено).
  - Леммы 3.1–3.3, предложение 4.3, лемма 4.5 и замечание 4.4 проверены построчно — верны.
- **Новизна:** по сырому файлу данных репозитория Гордона (коммит 5b3d729 от 24.04.2026 — действительно
  последний; 15536 записей) все шесть пар имеют статус `Open`; в таблице известных proper CW на сайте
  (обновлён 3.09.2026) и в Table 7 arXiv:2501.14924 ни одна из них не встречается (включая семейства
  «cm»); CW(168,12) — `Open`, CW(252,12) — `No`, так что CW(504,144) какого-либо вида ранее не было
  известно. Восемь случаев Тана (arXiv:2608.18468) — все несуществование, 146 среди них нет; 146 и не
  было «открытым» в таблице Штрасслера, поскольку непроперный CW(146,64) существует (подъём CW(73,64)).
  Семейство 2(q²+q+1) — это ровно отозванный случай n = (q−1)/2 теоремы 6.6 AGZ (исправлена Гордоном,
  Theorem 13 даёт только нечётные n′) и ответ на Open Problem 7 слайдов Люна–Ма (w = 4 там исключено).
  Итог: шесть новых параметров — новые; гипотеза о «близнеце» открыта, но численные свидетельства
  сильные (62 значения q). Статью Кренгеля (SETA 2004) проверить по-прежнему не удалось.
