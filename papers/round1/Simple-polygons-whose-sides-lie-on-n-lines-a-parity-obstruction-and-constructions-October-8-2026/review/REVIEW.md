# Рецензия на статью «Simple polygons whose sides lie on n lines: a parity obstruction and constructions»

Дата проверки: 8 октября 2026. Оригинальные файлы сохранены в `review/orig/`.

## Вердикт

Математика статьи верна. Все четыре конструкции (18/7, 33/9, 55/11, 78/13) независимо перепроверены
в точной рациональной арифметике (`scripts/verify_constructions.py`). Теорема о чётности подтверждена
полным перебором всех простых расположений псевдопрямых при n ≤ 9 (62, 24 698 и 112 018 190 классов
коммутации, `scripts/enumerate_classes.c`): число компонент G всегда имеет предсказанную чётность,
каждый цикл содержит нечётное число A-пересечений, при n = 7 и n = 9 граф G никогда не связен.
Следовательно M(7) = 18, M(9) = 33, M(11) = 55, M(13) = 78 — верно.

## Проверка доказательств (вручную)

- Предложение 2.3 (редукция): корректно. Часть 2 — дополнение замкнутого следа в K_n (n нечётно)
  имеет чётные степени, непустое ⇒ содержит цикл ⇒ ≥ 3 рёбер. Часть 1 — из попарной различности
  вершин следует простота расположения, а из дизъюнктности непоследовательных сторон — что на
  каждой прямой стороны суть [p1,p2],[p3,p4],….
- Лемма 3.2 (sweep): корректна. Проверил случаи (B),(C),(A), инварианты (I1) (непересекаемость
  паросочетания высот; перебор взаимного расположения пар исчерпывающий) и (I2) (нечётность
  разностей), а также изменения Λ_C при каждом типе шага (0, 0, 0, +1, −(b−i−1), a−i).
- Лемма 3.3 (#A ≡ r(r+1)/2): корректна, включая коммутационные/braid-ходы и подсчёт для
  bubble-sort слова. Единственная внешняя зависимость — теорема Мацумото–Титса; цитировался только
  Мацумото.
- Следствие 1.3 и арифметика (n²−1)/8 = r(r+1)/2, r(r+1)/2 чётно ⇔ n ≡ ±1 (mod 8): верно.
- Lean-чекер (`lean/Main.lean`): определения `orient`, `segInter`, `isSimplePolygon`,
  `sidesOnLines` прочитаны; условия на индексы непоследовательных сторон покрывают ровно нужные
  пары; однородные координаты с w > 0 корректны. Lean в этой среде не установлен, перезапустить
  проверку не удалось; `lean_output.txt` и данные в `data/*.json` согласованы с `Main.lean`
  (проверено скриптом).

## Найденные недочёты (исправлены)

1. `limitations.tex`: фраза «it has 2 or at least 3 components» для n = 7, 9 неточна. Заменена
   точными распределениями: n=7 — 2/4/6 компонент (7870/10220/6608 классов), n=9 — 2,4,6,8,10.
2. Зависимость леммы 3.3 от теоремы Мацумото–Титса устранена: найдена явная потенциальная функция
   Φ(π) = Σ_h [π(h) нечётно]·⌊h/2⌋ + #{скрестившиеся пары (x<y): x нечётно, y чётно},
   изменение которой на каждом пересечении ≡ A-статусу (mod 2). Проверено перебором всех
   перестановок и подъёмов при n ≤ 8 (`scripts/potential_check.py`). Это закрывает открытый вопрос 4
   оригинала. Старое доказательство оставлено как Remark 3.4 с добавленной ссылкой на Tits (1969).
3. Висячие ссылки на несуществующие каталоги (`attempts/A09-polygon-lines/scripts/`,
   `attempts/bin/leanchk`) в README и §5 заменены на скрипты в `scripts/` этой же папки.
4. Отсутствовал обзор смежной литературы. Добавлен абзац «Relation to arrangement graphs»:
   простой C(n,2)-угольник = гамильтонов цикл графа расположения, поворачивающий в каждой вершине;
   ссылки на Bose–Everett–Wismath (2003; негамильтоновы графы расположений при n=6 и нечётных n>6),
   Felsner–Hurtado–Noy–Streinu (2006), Scharf–Scherfenberg (2011), Ackerman–Pinchasi–Scharf–
   Scherfenberg (2013; inducing polygons), Goodman (1980) и Felsner–Goodman (2017) для wiring diagrams.
5. Неподтверждаемое утверждение «A linear-algebra search over GF(2) suggests that such potentials
   exist» удалено (заменено самим потенциалом).
6. Мелочи: описание конструкций автора вопроса на MO уточнено (его примеры для n = 7, 9, 10
   самопересекающиеся); в Remark 2.4 добавлено обоснование обратного утверждения; уточнено, что
   классы коммутации = простые расположения псевдопрямых с пронумерованными проводами.

## Новизна

- Вопрос на MathOverflow (513798, 31 июля 2026) на 8 октября 2026 без ответов (проверено через
  API Stack Exchange); в комментариях лишь экспериментальные данные DSM (24-угольник на 8 прямых,
  18 на 7).
- Поиск по литературе: задача о максимуме числа сторон, «alternating 2-factor» и чётность числа его
  компонент в литературе не найдены. Ближайшие результаты — гамильтоновость графов расположений
  (Bose–Everett–Wismath 2003: существуют негамильтоновы графы при нечётных n > 6 — утверждение
  о *некоторых* расположениях, тогда как статья даёт запрет для *всех* расположений при
  n ≡ ±1 (mod 8)) и inducing polygons (ровно одна сторона на прямой). Результаты статьи —
  обструкция по чётности, точные значения M(7), M(9), M(11), M(13) — по всем признакам новые.
- Оценка: содержательный, но небольшой результат: полностью отвечает на вопрос MO для n = 7
  (невозможность 21) и опровергает гипотезу для бесконечной серии n ≡ ±1 (mod 8); уровень —
  короткая заметка в журнале по дискретной геометрии / ответ на MO.
